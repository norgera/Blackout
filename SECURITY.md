# Security Policy

## Supported Version

Only the latest publicly released version of Blackout receives security updates.

## Reporting a Vulnerability

Functional defects with no security impact are regular application bugs and should be reported through [GitHub Issues](https://github.com/norgera/Blackout/issues).

Use the [GitHub private vulnerability reporting form](https://github.com/norgera/Blackout/security/advisories/new) for security vulnerabilities that could allow an attacker to execute unauthorized code or commands, access information they should not have access to, or otherwise compromise the security of the system through Blackout.

A report should include the affected Blackout version, a description of the vulnerability and how it can be exploited, its potential impact, and the steps required to reproduce it.

Reports will be reviewed as soon as possible. Blackout is developed in spare time, so no specific response or resolution timeframe can be guaranteed.
